# Installation von JuraOS

## Windows – einfacher Start

1. Öffne https://github.com/RedstarLabs/JuraOS.
2. Klicke auf `Code` und anschließend auf `Download ZIP`.
3. Entpacke die ZIP-Datei in einen Ordner, zum Beispiel `Dokumente/JuraOS`.
4. Installiere und öffne Obsidian Desktop.
5. Wähle `Vault öffnen` beziehungsweise `Ordner als Vault öffnen`.
6. Öffne den Ordner `JuraOS/vault`.

Fertig. Für diesen Weg brauchst du kein GitHub-Konto und kein Git.

## Linux

1. Lade das Repository herunter oder klone es mit Git.
2. Installiere Obsidian Desktop.
3. Öffne in Obsidian den Ordner `vault/` als Vault.

## Aktualisierungen

Für gelegentliche Nutzung genügt ein erneuter Download der aktuellen Version.
Ersetze dabei nicht unüberlegt einen bestehenden Ordner mit persönlichen Notizen.

Wer JuraOS regelmäßig aktualisieren möchte, kann Git installieren und das
Repository klonen. Aktualisierungen erfolgen dann mit `git pull`.

## Persönliche Daten

- Persönliche Mitschriften und Lernstände gehören nicht in das öffentliche Repository.
- Bei Git-Nutzung werden Dateien in den ausdrücklich ignorierten persönlichen
  Ordnern nicht versioniert.
- Für umfangreiche persönliche Materialsammlungen empfiehlt sich ein separater Vault.
- PDFs und andere geschützte Dokumente nicht öffentlich hochladen.

## Voraussetzungen

- Obsidian Desktop
- Git nur für Klonen und komfortable Aktualisierungen
