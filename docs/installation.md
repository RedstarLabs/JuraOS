# Installation

## Linux

1. Git installieren.
2. Repository klonen oder herunterladen.
3. Obsidian Desktop installieren.
4. In Obsidian den Ordner `vault/` als Vault öffnen.

## Windows

1. Git installieren oder das Repository als ZIP herunterladen.
2. Obsidian Desktop installieren.
3. Repository entpacken beziehungsweise klonen.
4. In Obsidian den Ordner `vault/` als Vault öffnen.

## Persönliche Nutzung

Für persönliche Mitschriften und Lernmaterialien empfiehlt sich ein
separater Vault außerhalb des Repositorys.

PDFs und andere persönliche Dokumente nicht in das öffentliche
Repository aufnehmen.

## Aktualisierungen

Die gemeinsame Plattform wird über das offizielle Repository gepflegt.
Persönliche Lernstände sollen unabhängig davon bleiben.
