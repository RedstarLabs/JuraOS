# Zusammenarbeit mit GitHub

## Maintainer

Das offizielle Repository wird ausschließlich durch den Maintainer
verwaltet. Andere Nutzer erhalten keine Schreibberechtigung.

## Nutzer

Die Plattform kann heruntergeladen und lokal verwendet werden.
Lokale Änderungen benötigen keine GitHub-Berechtigung.

## Sicherheit

Vor jedem Commit und Push:

1. `git status` ausführen.
2. `git diff --cached` prüfen.
3. Sicherstellen, dass keine persönlichen Daten enthalten sind.
4. Erst danach committen und pushen.

`.gitignore` verhindert nicht, dass bereits versionierte Dateien
erneut aufgenommen oder veröffentlichte Daten aus der Historie
entfernt werden.
