# Lokale Vorlesungsunterlagen

Dieser Ordner ist für persönliche Vorlesungs-PDFs und individuelle
Quellennotizen vorgesehen.

Die Inhalte dieses Ordners sind durch `.gitignore` vom öffentlichen
JuraOS-Repository ausgeschlossen. Nur diese README ist ausgenommen.

Lege PDFs und die dazugehörigen Markdown-Quellennotizen hier ab.
Verknüpfe jede Quellennotiz mit der passenden Lehrveranstaltung.
