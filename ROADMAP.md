# JuraOS Roadmap

JuraOS wächst schrittweise mit den tatsächlich belegten Lehrveranstaltungen.
Neue fachliche Themen werden erst ergänzt, wenn sie benötigt werden.

## Version 0.1.0 – Fundament

- [x] Grundstruktur des Obsidian-Vaults
- [x] Entwicklungsordner und Repository
- [x] Dokumentation zu Installation, Workflow und Zusammenarbeit
- [x] Vorlagen für Definitionen, Fälle, Quellen und Wochenplanung
- [x] Vorlagen für Prüfungsschemata und Karteikarten
- [x] Startseite und Semester-Dashboard
- [x] Datenschutzregeln für persönliche Inhalte
- [x] Navigation und interne Links geprüft
- [ ] Gesamte Installation auf Linux und Windows testen
- [ ] Endgültigen Stand prüfen und veröffentlichen

## Version 0.2.0 – Lernworkflow

- [x] Semester- und Wochenplanung
- [x] Übersicht für Karteikarten
- [x] Übersicht für Prüfungsschemata
- [x] Fälle und Fehleranalyse strukturiert erfassen
- [ ] Lernworkflow anhand tatsächlicher Vorlesungen erproben
- [ ] Wiederkehrende Abläufe bei Bedarf vereinfachen

## Version 0.3.0 – Quellen

- [x] Grundstruktur für Quellenverwaltung
- [x] Kategorien für Vorlesungsunterlagen, Skripte, Aufsätze, Urteile und Literatur
- [ ] PDF-Verweise und Seitenreferenzen im Lernalltag erproben
- [ ] Bedarf an Textextraktion prüfen und dokumentieren

## Spätere Erweiterungen

- [ ] Automatische Qualitätsprüfungen bei erkennbarem Nutzen
- [ ] Optionale lokale Suche evaluieren
- [ ] Integration mit JuraAI evaluieren
- [ ] Weitere Lehrveranstaltungen erst bei Bedarf ergänzen

## Arbeitsprinzip

JuraOS bleibt bewusst einfach. Neue Funktionen werden nur aufgenommen,
wenn sie einen konkreten Nutzen für Organisation, Verständnis oder Anwendung
juristischer Inhalte bieten.
